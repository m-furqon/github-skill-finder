# Contributing

Thank you for improving GitHub Skill Finder.

## Contribution guidelines
- Keep instructions clear, evidence-based, and suitable for Gemini Apps.
- Do not add claims about platform support without reliable documentation.
- Do not add repository examples unless their URLs and files have been verified.
- Do not execute third-party code as part of review.
- Preserve the distinction between compatibility, security review, and installation testing.
- Update `CHANGELOG.md` for meaningful changes.

## Suggested improvements
- Better search query patterns.
- Clearer compatibility tests based on official Gemini documentation.
- More robust duplicate-analysis criteria.
- Better license and supply-chain review guidance.
- Improved examples and reporting templates.

## Pull request checklist
- [ ] Documentation updated.
- [ ] No invented facts or unsupported compatibility claims.
- [ ] Security implications considered.
- [ ] Changelog updated.
