# Security Policy

## Reporting a concern
If you find unsafe instructions, credential requests, data-exfiltration behavior, or misleading security claims in this project, open a GitHub issue with the affected file and a concise description. Do not include passwords, API keys, tokens, or private user data.

## Scope
This project provides instruction text for researching and assessing third-party GitHub skills. It does not execute third-party code. Security review is limited by the files and evidence available during inspection.

## Responsible use
- Never run unknown repository scripts merely because this Skill recommends a repository.
- Review permissions and external connections before using a third-party skill.
- Re-check repository contents before installation because upstream content can change.
