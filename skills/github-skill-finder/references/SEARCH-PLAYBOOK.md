# Search Playbook

## Broad discovery queries
- `site:github.com "SKILL.md" "agent skills"`
- `site:github.com "SKILL.md" research`
- `site:github.com "SKILL.md" productivity`
- `site:github.com "SKILL.md" data analysis`
- `site:github.com "SKILL.md" design`
- `site:github.com "SKILL.md" education`
- `site:github.com "SKILL.md" marketing`
- `site:github.com "SKILL.md" cybersecurity`
- `site:github.com "SKILL.md" writing`
- `GitHub awesome agent skills collection`

## Search process
1. Translate the user need into task terms and synonyms.
2. Search at least two phrasings for broad requests.
3. Inspect repository pages rather than relying on snippets.
4. Locate individual skills inside collections.
5. Open the actual `SKILL.md`.
6. Inspect README, license, releases/commits, dependencies, and supporting files.
7. Record exact paths and canonical links.

## Avoid false positives
- A collection is not necessarily a single skill.
- A plugin, MCP server, CLI, app, or API is not automatically a Gemini Apps Skill.
- A README reference is not proof of a `SKILL.md`.
- Stars and forks do not prove quality or safety.
