# Scoring Model (100 points)

| Criterion | Maximum | Evidence |
|---|---:|---|
| Task relevance | 25 | Match to user's stated outcome |
| Gemini Apps compatibility | 25 | Instruction-led design and runtime requirements |
| Documentation and clarity | 15 | Clear SKILL.md, README, examples, setup |
| Maintenance evidence | 10 | Visible commits, releases, issue activity |
| Security posture | 15 | Findings from inspected content |
| License clarity | 5 | Explicit and understandable license |
| Practical completeness | 5 | Useful workflow, references, examples |

## Rules
- Missing evidence receives no unsupported credit.
- B, C, and U compatibility classes cannot receive full compatibility points.
- High-risk candidates are excluded from recommended results.
- State whether the score is provisional.
- Scores are comparative judgments, not safety certifications or endorsements.
