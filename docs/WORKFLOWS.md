# Workflows

## Find skills
User describes a task → search GitHub → verify SKILL.md → assess compatibility → audit risk → rank shortlist.

## Audit a repository
User provides URL → inspect repository and skill file → inspect dependencies and license → report evidence and concerns.

## Adapt a skill
Inspect source → check license → inventory unsupported features → rewrite portable workflow → document limitations → prepare Gemini Apps package.

## Build a collection
Select complementary skills → detect overlap → check licenses → create manifest and folder plan → avoid redistributing third-party files without permission.
